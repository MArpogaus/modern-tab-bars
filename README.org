** About The Project

Emacs has two rows of tabs.  The =tab-bar= shows one tab per tab or tab
group; the =tab-line= shows one tab per buffer of a window.  This
package gives both the look of the editors people come here from: a
coloured indicator beside the selected tab, an icon on every tab, and a
close button that closes what you expect.

[[file:img/screenshot-light.png]]

[[file:img/screenshot-dark.png]]

The two modes are independent, they take the same kinds of
customization, and every option of one has a twin in the other.  Icons
come from [[https://github.com/rainstormstudio/nerd-icons.el][nerd-icons]] where it is installed and the frame has the font.
Where it is not, every glyph falls back to a plain character, so a
terminal shows the same tabs in ASCII.

** Getting Started

*** Installation

The package is one Emacs and nothing else.  With =use-package= and a
package manager that installs from a repository:

#+begin_src emacs-lisp
  (use-package modern-tab-bar
    :vc (:url "https://github.com/MArpogaus/modern-tab-bars")
    :hook (after-init . modern-tab-bar-mode))

  (use-package modern-tab-line
    :vc (:url "https://github.com/MArpogaus/modern-tab-bars")
    :hook (after-init . modern-tab-line-mode))
#+end_src

*** Usage

=M-x modern-tab-bar-mode= dresses the tab bar.  Turn on =tab-bar-mode=
to see it.

=M-x modern-tab-line-mode= dresses the tab line, and turns
=global-tab-line-mode= on with it.  A window showing one buffer hides
its tab line: a row with a single tab on it says nothing and costs a
line of every window.  Set =modern-tab-line-auto-hide= to nil to keep
the row.

Turning either mode off gives the stock look back, including the
buttons.

** Customization

*** The Indicator

The indicator is the vertical bar beside a tab.  Both modes take the
same two options for it, and both read them the same way: the car
belongs to the selected tab, the cdr to the others.

| Option                                      | Default              |
|---------------------------------------------+----------------------|
| =modern-tab-bar-active-indicator-width=     | ~4~, in pixels       |
| =modern-tab-bar-inactive-indicator-width=   | ~2~, in pixels       |
| =modern-tab-bar-active-indicator-color=     | ~mode-line-emphasis~ |
| =modern-tab-bar-inactive-indicator-color=   | ~shadow~             |
| =modern-tab-bar-indicator-height=           | ~25~, in pixels      |
| =modern-tab-line-active-indicator-width=    | ~3~, in pixels       |
| =modern-tab-line-inactive-indicator-width=  | ~0~, in pixels       |
| =modern-tab-line-active-indicator-color=    | ~mode-line-emphasis~ |
| =modern-tab-line-inactive-indicator-color=  | ~shadow~             |
| =modern-tab-line-indicator-height=          | ~20~, in pixels      |

A width of nil or zero draws no indicator at all.  A colour is a colour
name or a face, whose foreground is then the colour.  A terminal has no
images and draws one column of a vertical line instead.

*** The Tab Bar

| Option                             | What it says                                  |
|------------------------------------+-----------------------------------------------|
| =modern-tab-bar-icons=             | the icon each group name shows, an alist       |
| =modern-tab-bar-default-icon=      | the icon a group with no match shows           |
| =modern-tab-bar-group-name-function= | rewrites the name of a group                 |
| =modern-tab-bar-new-command=       | what the new button runs                       |
| =modern-tab-bar-new-icon=          | how the new button is drawn                    |
| =modern-tab-bar-close-icon=        | how the close button is drawn                  |
| =modern-tab-bar-current-glyphs=    | the mark on the selected tab, best first       |
| =modern-tab-bar-format=            | what the bar shows, as =tab-bar-format= takes it |

An icon is a string shown as it is, or a plist naming a nerd-icons
glyph:

#+begin_src emacs-lisp
  (setopt modern-tab-bar-icons
          '(("HOME"      :style "suc" :icon "custom-emacs")
            ("^\\[P\\]"  :style "oct" :icon "repo")
            ("config"    :style "md"  :icon "cog")))
#+end_src

The first pattern that matches the group name wins, and the patterns
are matched with the case rules of whoever wrote them.

*** The Tab Line

| Option                           | What it says                             |
|----------------------------------+------------------------------------------|
| =modern-tab-line-icon-function=  | the icon of a tab, called with its buffer |
| =modern-tab-line-close-glyphs=   | the close button, best first              |
| =modern-tab-line-auto-hide=      | whether a window with one buffer hides the row |

The close button closes what an editor would: the buffer is buried
where another window still shows it, killed where none does, and the
window goes with its last tab.

** Development

| Target        | What it does                             |
|---------------+------------------------------------------|
| =compile=     | byte-compile, warnings are errors        |
| =checkdoc=    | documentation style, any output fails    |
| =lint=        | package-lint, the rules MELPA applies    |
| =relint=      | the regular expressions                  |
| =test=        | ERT suite                                |
| =complexity=  | what each function costs a reader        |
| =clean=       | remove build output and the tool sandbox |

Plain =make= runs the checks in that order, exactly as the CI does.
=make complexity= is a report rather than a gate; see
[[file:docs/implementation.org][docs/implementation.org]] for what it counts and for how the two modes are
built.
